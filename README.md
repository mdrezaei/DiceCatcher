# Godot C# Game Project

## English
A game project developed using Godot 4.7.2 and C#.

### 🛠 Tech Stack
- **Engine:** Godot 4.7.2
- **Language:** C#
- **SDK:** .NET SDK 10
- **Runtime:** .NET Runtime 8
- **IDE:** Visual Studio 2026

### 🚀 Getting Started
To run this project locally, you need to have the following installed:
1. Godot 4.7.2
2. .NET SDK 10
3. Visual Studio 2026

Clone the repository and open the project in Godot. Build the C# solution using Visual Studio or the .NET CLI.
